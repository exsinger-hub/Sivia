# Sivia 外挂科研绘图知识库

为 **Paper → Overview → 可编辑 PPT** 提供可扩充的视觉参考。Sivia 按论文领域、科学对象、方法关系与构图需求选择案例，把参考中的表达方式用于新论文的设计；确认 Overview 并要求制作 PPT 后，继续生成可编辑图件。

当前有 **10 个已认可案例**，覆盖五类科研方向。D4RT、AutoTool、SigmaDock 为 **3 个审阅草稿**，单独标记。下方逐项展示 Overview 图片，卡片可打开原图、制作记录和案例详情。

## 接入你的课题组案例

向 Sivia 提供参考图片、已有案例目录或认可的作品，并说明希望延续的构图、配色与版面。当前论文负责科学内容，外挂案例库提供视觉表达参考。通过审阅的作品和修订经验可以保留在本地，在后续任务中继续使用。

制作记录保留每张图对应的完整生成输入，方便追溯与复用。可编辑 PPTX 也可作为案例附件保存；公开贡献方式见[贡献指南](CONTRIBUTING.md)。
