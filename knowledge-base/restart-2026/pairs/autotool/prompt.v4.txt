SCIENTIFIC CLAIM

At an agent decision step, AutoTool first attempts to identify a likely next tool from its Tool Inertia Graph. It combines historical frequency with relevance to the current context. Only a sufficiently strong candidate proceeds to parameter filling. Parameter filling follows an ordered hierarchy: dependency backtracking, environmental state matching, and heuristic filling. Direct tool execution through the inertial route is permitted only when a tool candidate passes the selection threshold and every required argument has been filled. If tool selection fails, or any required parameter remains undetermined, the decision returns to the standard LLM route. Both routes ultimately produce a tool call that executes in the same environment and returns an observation.

The graph has two levels of node: tool nodes and parameter nodes associated with those tools. Tool-sequence edges represent sequential relations between tool invocations. Parameter-dependency edges represent reuse or transfer of parameter values. These edge types cannot be combined into one undifferentiated arrow network. The graph is constructed and updated from execution trajectories. It may be bootstrapped, but the paper's reported experiments use cold-start online construction. The figure explains the method's decision logic; it does not claim that an offline dataset is mandatory at inference or that the illustrated history is a measured benchmark trajectory.

The formal scoring expression allowed in the artwork is CIPS = (1−α) S_freq + α S_ctx. CIPS denotes Comprehensive Inertia Potential Score. S_freq represents frequency information from the graph. S_ctx represents contextual relevance between current task intuition and a candidate tool description. The selected candidate v* must satisfy CIPS(v*) > θ_inertial before the parameter stage. Do not print a chosen numerical threshold, weight, model name, speedup, token saving or success rate. This overview illustrates the decision mechanism, rather than the particular runtime cap and hyperparameters used in the experiment section.
